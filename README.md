# 设备监理师 · 考试与学习系统

面向 **注册设备监理师职业资格考试** 的个人备考系统。纯静态网页，无需安装、无需联网即可使用，可部署到 GitHub Pages 作为在线云文档。

> 依据《设备监理师职业资格考试大纲（2023）》与 2024 版教材整理；题库含历年习题与自编题，每题附解析。

## 考试规则（大纲规定）

| 科目 | 时长 | 题型 | 满分 | 合格 |
| --- | --- | --- | --- | --- |
| 设备监理基础知识和相关法规 | 2 小时 | 单选 50 + 多选 30 | 110 | 66 |
| 设备工程质量管理与检验 | 2 小时 | 单选 50 + 多选 30 | 110 | 66 |

## 本地使用

- 最简单：双击 `设备监理师考试系统-离线版.html`，全部数据与教材已内联，断网也能用。
- 开发方式：双击 `index.html`（数据按需加载 `data/book-*.js`）。
- 也可以启动本地服务：

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

## 部署

**方式一：任意静态托管（推荐，免安装）**

1. 把本项目目录（或 `设备监理师考试系统-部署包.zip` 解压后的内容）拖到 Netlify Drop、Vercel、Cloudflare Pages 等静态托管。
2. 入口文件选 `index.html`，无需构建命令，输出目录为根目录。
3. 拿到分配的域名即可访问。

**方式二：GitHub Pages**

```bash
git init
git add .
git commit -m "feat: 设备监理师考试与学习系统"
git branch -M main
git remote add origin https://github.com/<你的用户名>/sbjl-exam.git
git push -u origin main
```

然后在仓库 **Settings → Pages** 中选择 `main` 分支、`/ (root)` 目录，保存后访问：

```
https://<你的用户名>.github.io/sbjl-exam/
```

> 教材原文与题库仅限个人备考，公开部署前请自行评估版权风险；不想公开可把仓库设为私有，或只在自己电脑/手机上使用离线版。

## 数据说明

- 学习进度、错题、成绩只保存在浏览器 `localStorage`，不上传服务器；换设备/清缓存会丢失。
- 考试日期默认为 2027-09-11，可在右上角「设置」中改为官方公布日期。
- 题库与解析用于个人备考，不保证覆盖全部考点；以官方教材和大纲为准。
- 「法规旧版」与「规范详解」来自扫描件 OCR，个别字句可能存在识别误差，阅读时以原书或 2024 版教材为准。
